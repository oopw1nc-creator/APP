# 利克金商贸手机进销存 Android APK

本版 V1.1 针对手机实际使用问题做了完整修正：

1. 新增商品页面改为可适应手机软键盘的滚动弹窗，输入商品名称时不会再被输入法完全遮挡。点击关闭、取消、保存商品均会强制关闭弹窗。
2. 客户清单打印/预览页面强制使用白底蓝字，并关闭深色配色继承，保证商品、数量、金额等内容清晰可读。
3. Android WebView 使用 adjustResize，并处理软键盘/系统导航栏安全区域。
4. APP 启动时强制关闭所有弹窗，避免安装后误显示新增商品页面。
5. 顶部四项导航保持在页面最上方，页面底部不再放置业务导航。

GitHub Actions 已配置，可直接手动运行 workflow 编译 APK。
